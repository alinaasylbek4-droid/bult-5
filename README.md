# Lab Branches
Учебный проект: простая веб-страница, на которой отрабатывается работа с ветками Git.

## Development setup
1. Clone the repository: `git clone <url>`
2. Switch to the develop branch: `git switch develop`
3. Open `index.html` in a browser

## Guidelines
Branching rules are described in the additional guide document (Git branching guide).
